# cube自动注册问题修复

2026年3月10日，用户报告并修复了cube不能自动注册的问题。问题的根本原因是`ensure_cube_registered()`函数在目标cube目录不存在时，会先检查默认模板cube（dev_cube）是否存在，如果模板也不存在就直接放弃返回错误，完全不尝试通过环境变量回退创建配置。而`ensure_cube_directory()`→`_build_cube_config()`已有完整的两级回退机制：1)有模板→克隆，2)没模板→从.env环境变量构建。修复措施包括：在`mcp-server/cube_manager.py`中移除`ensure_cube_registered`中多余的模板前置检查，直接调用`ensure_cube_directory`；在`mcp-server/handlers/admin.py`中使`handle_memos_register_cube`在找不到cube时能自动创建目录；在`mcp-server-node/src/cube-manager.ts`和`mcp-server-node/src/handlers/admin.ts`中也同样移除了模板前置检查并支持自动创建。验证方法是用不存在的project_path `/mnt/g/test/test-auto-cube`调用memos_search，成功自动创建了`test_auto_cube` cube目录+config.json并注册到API。
