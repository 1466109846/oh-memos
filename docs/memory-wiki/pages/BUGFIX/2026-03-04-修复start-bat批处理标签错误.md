# 修复start.bat批处理标签错误

2026年3月4日上午8:15，用户修复了start.bat运行时报错‘系统找不到指定的批处理标签 - wait_port_loop’的问题。错误原因是wait_port子程序中的内部goto标签在用户环境下解析异常。修复方法是将wait_port改为使用for /l轮询实现，不再依赖子标签跳转；同时保留Neo4j和Qdrant的非阻塞后台启动方式：Neo4j优先执行start-Neo4j.bat，失败时回退到neo4j.bat start；Qdrant使用PowerShell的Start-Process命令启动。
