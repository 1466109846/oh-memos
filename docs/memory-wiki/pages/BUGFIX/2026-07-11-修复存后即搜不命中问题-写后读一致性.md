# 修复存后即搜不命中问题(写后读一致性)

在2026年7月11日，用户修复了 oh-memos 项目中存后即搜不命中的写后读一致性问题。根因是 neo4j_community.py 的 Cypher 查询缺少 ORDER BY 导致返回任意顺序，以及 start_api.py 的 /search 未转发 MCP 的 top_k 参数。修复方案为：在 neo4j_community.py 的 get_all_memory_items 中增加 ORDER BY coalesce(n.updated_at,n.created_at) DESC 并删除多余 print；在 start_api.py 的 SearchRequest 中增加 top_k 字段并转发给 mos.search。用户通过存入 PROBE-FB9977 并立即搜索命中且排第1进行了验证。
