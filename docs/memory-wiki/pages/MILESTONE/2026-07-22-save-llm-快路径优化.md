# save LLM 快路径优化

用户在 core.py 中新增对 ^\[TYPE\] 前缀内容直接走 _make_memory_item verbatim 保存的逻辑，开启 MOS_TYPED_SAVE_FAST（默认 true），从而削减了 save 的主延迟和 LLM 超时熔断场景。
