# Cube彻底删除三处清理

为实现对 cube 的彻底删除，用户在系统中必须同步清除三处数据：1) Neo4j：所有 cube 共享单库，依据节点属性 user_name=cube_id 逻辑隔离，删除语句为 MATCH (n:Memory) WHERE n.user_name=$cube DETACH DELETE n；2) Qdrant：每个 cube 对应一个名为 {cube_id}_graph 的 collection，使用 delete_collection 删除；3) 文件系统：删除 MEMOS_CUBES_DIR/{cube_id}/ 目录及其 config.json。此前系统只能创建 cube，缺乏删除能力。
