# 三重删除保护机制

用户在删除 cube 前实现了三重保护：① 二次确认，必须输入 cube 名称并经后端校验（confirm==cube_id），否则返回 400；② 干跑预览（/delete-preview 端点），仅统计将被删除的内容不实际修改；③ 删除前自动导出该 cube 的 JSON 备份至 backups/。db_admin.py 对每个数据源采用独立 try‑catch 容错，单源故障不影响其他，app.py 使用同步 def 端点避免阻塞事件循环。
