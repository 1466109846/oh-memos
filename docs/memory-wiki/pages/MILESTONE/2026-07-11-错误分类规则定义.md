# 错误分类规则定义

用户定义了明确的错误分类规则：超时、连接错误、WinError10053-10054、5xx服务器错误归类为瞬时错误，采用指数退避重试后再降级；429限流、insufficient balance/quota/欠费、鉴权401-403错误归类为永久错误，跳过重试立即降级。
