# API启动慢根因分析

用户识别出API启动缓慢的根本原因是startup_auto_register串行注册cubes目录下所有11个cube，每个cube的init_from_dir方法会依次初始化Neo4j driver、Qdrant collection、LLM client、Embedder和Reranker，全部串行执行导致耗时过长。
