# 验证历史记忆检索功能

在2026年3月4日上午9:43，用户在 oh-memos 项目中验证历史记忆检索功能时发现：使用 cube_id='memos_cube' 可正常调用 memos_search 并返回历史记忆；而使用 cube_id='memos_cube_graph' 则报错 CUBE_REGISTRATION_FAILED（未找到）。用户据此推断 memos_cube_graph 更可能是底层向量存储的命名，而非可直接用于检索的 cube_id。
