# 根因分析：行内注释污染 API key

The root cause was identified as inline comments in the .env file causing API key pollution. Specifically, lines 76 and 104 of /mnt/g/test/oh-memos/.env contained unquoted values with trailing inline comments (e.g., OPENAI_API_KEY=<key>    # API 密钥), which caused python-dotenv to include the comment text as part of the token when passed to LongCat LLM and SiliconFlow embedder, resulting in 401 Authentication failed errors.
