# 修复方案：移动注释或加引号

The fix involved either moving inline comments above the variable definition (e.g., placing # API 密钥 on its own line before KEY=value) or enclosing the value in quotes (KEY="value"  # comment). This prevents python-dotenv from parsing the comment as part of the token.
