# 项目路径和配置文件位置

The project is located at /mnt/g/test/oh-memos (mounted from G:\test\oh-memos on Windows). The primary configuration file is .env in the root directory. Note that src/.env may exist but is ignored because load_dotenv() searches upward from cwd and prioritizes the root .env; thus, src/.env has no effect.
